# Fitness Tracker Dashboard

## What is this?
This is a web-based fitness tracker dashboard that allows users to enter meals, track calories, view a meal log, and monitor their total daily calorie intake.

## Why does it exist?
This project exists to provide a simple and focused calorie tracking tool for users who want to stay aware of their eating habits and support fitness or weight-loss goals without using a more complicated app.

## What tools did I use?
I used HTML, CSS, and JavaScript to build the project because they provide a simple and direct way to create a functional interactive web app. I used GitHub to store the project files and GitHub Pages to deploy the site online. I also used ChatGPT to help with planning the structure, improving the layout, and troubleshooting code.
