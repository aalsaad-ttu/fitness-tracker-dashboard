# Fitness Tracker Dashboard

## What is this?
This is a web-based fitness tracker dashboard that allows users to log meals, track calories, monitor protein intake, and manage their daily nutrition goals. Users can add meals, remove meals, clear all entries, and view updated totals in real time.

## Why does it exist?
This project exists to provide a simple and focused nutrition tracking tool for users who want to stay aware of their eating habits without using a more complicated or subscription-based app. The goal was to create a clean and functional dashboard that supports basic fitness and weight-loss goals.

## What tools did I use?
I used HTML, CSS, and JavaScript to build the project because they provide a simple and direct way to create an interactive web application. I used GitHub to store and manage the project files and GitHub Pages to deploy the site online. I also used ChatGPT to help with planning features, improving the layout, debugging code, and implementing interactive functionality.

## What changed from Project 01 to Project 02?
Project 02 added several major improvements compared to Project 01. The application now includes protein tracking, delete meal functionality, a clear all meals feature, and local storage so meals remain saved after refreshing the page. The layout and styling were also improved to create a more polished and responsive design across different screen sizes. These changes made the project feel more complete, functional, and realistic as a fitness tracking tool.
