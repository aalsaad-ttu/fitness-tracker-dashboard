About This Tracker

Many fitness apps include too many features or require subscriptions. This tracker focuses on the essentials: logging meals, counting calories, and tracking protein.

This final MVP improves on Project 01 by adding protein tracking, delete buttons, a clear all option, saved meals using local storage, and a more polished responsive layout.
